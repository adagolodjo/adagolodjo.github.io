  </div>

  <div class="li-comp-card c3">

    <div class="li-comp-verbs">Identifier · Distinguer · Décrire · Préparer</div>
    <ul class="li-comp-skills">

      <li>Structure d'un système automatisé (PO / PC)</li>
      <li>Lien API → IoT → Jumeau numérique</li>
