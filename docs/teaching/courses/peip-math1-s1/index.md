    <h2 class="section-title">Présentation du cours</h2>
  </div>

  <p style="font-size: 1.1rem; line-height: 1.7; color: #555; margin-bottom: 2rem;">
    Ce module d'introduction, dispensé sur les premières semaines du parcours PeiP (Parcours des Écoles d'Ingénieurs Polytech), consolide les bases de <strong>trigonométrie</strong> et de <strong>calcul vectoriel dans le plan</strong> nécessaires à l'ensemble des enseignements scientifiques qui suivront. L'accent est mis sur les calculs simples de physique et la géométrie analytique.
  </p>

  <div class="info-box">

      <h4>{% include ph.html name="check-circle" %} Manipuler les formules essentielles</h4>

    </div>
    <div class="objective-card">
      <h4>{% include ph.html name="arrow-up" %} Représenter des vecteurs du plan</h4>

    <div class="objective-card">
      <h4>{% include ph.html name="ruler" %} Utiliser le produit scalaire</h4>
