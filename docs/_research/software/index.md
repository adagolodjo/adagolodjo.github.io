## Research Software

### Simulation & Modeling Tools

#### **CONECT Simulator**
A real-time simulation framework for needle insertion procedures in soft tissues.

**Features:**
- Finite element method (FEM) simulation
- Real-time haptic feedback
- Augmented reality visualization
- Surgical planning capabilities

**Status:** Under development  
**Technologies:** C++, OpenGL, SOFA Framework

#### **Soft Robotics Control Library**
A comprehensive library for controlling soft robots using Cosserat rod theory.

**Features:**
- Real-time deformation modeling
- Constraint-based control
- Multi-segment soft robot support
- ROS integration

**Status:** Open source (coming soon)  
**Technologies:** Python, C++, ROS

### Development Tools & Utilities

#### **Medical Image Processing Toolkit**
Tools for processing and analyzing medical images in surgical applications.

**Features:**
- DICOM image processing
- 3D reconstruction
- Segmentation algorithms
- Visualization tools

**Status:** Research prototype  
**Technologies:** Python, ITK, VTK

#### **Robotic Simulation Environment**
A simulation environment for testing robotic surgical procedures.

**Features:**
- Physics-based simulation
- Sensor modeling
- Path planning algorithms
- Performance metrics

**Status:** In development  
**Technologies:** Gazebo, ROS, Python
